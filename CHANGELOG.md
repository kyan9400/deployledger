# Changelog

## [0.1.0] - 2026-08-28

Initial public release.

- Added a FastAPI release-operations API with SQLite/Postgres support.
- Added idempotent deployment ingestion, signed GitHub webhooks, and hash-linked audit events.
- Added DORA delivery metrics and a responsive React dashboard with an explicit demo mode.
- Added Docker Compose, Kubernetes/Kustomize, Terraform, CI, container scanning, and runbooks.
